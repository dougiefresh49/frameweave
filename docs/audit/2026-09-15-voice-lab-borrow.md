# What frameweave borrows from voice-lab (2026-09-15)

Read-only pass over `~/projects/voice-lab` (pipeline scripts, docs, decisions, one WhisperX output, the worker log in the workspace). voice-lab turns DVD rips and YouTube pulls into per-character voice clips: center channel, Demucs, WhisperX with diarization, embedding verification, casting reels. Most of it is out of scope here. The parts below are the same problems this tool has, already solved on this Mac, and each is a pattern to carry, never code to copy across repos.

## Looked at and left

- Demucs vocal isolation, pyannote diarization, speaker embeddings, casting reels, ElevenLabs: not this tool's job. Diarization is Q13 and defaults to no.
- Gemini as the vision provider: voice-lab uses `gemini-3.7-flash` for identification with a note that flash-lite is the cheap tier. Doug asked for the GPT line here; Gemini 2.5 Flash-Lite stays the fallback and the spike measures both.
- The second Gemini key as a 429 fallback (`GEMINI_API_KEY_2`): a workaround for one provider's rate limit; the plan's retry with `Retry-After` covers it.
- Slack pings from workers: overnight batch posture; this tool's runs are minutes.
