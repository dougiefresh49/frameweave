User wanted front/back turnaround frames of a game character from a signed-URL turntable webm and asked if the repo's tooling could help [L3]. The assistant skipped the analyzer and did raw ffmpeg extraction/compositing [L15]; the session sprawled ~4.5 hours into a poster-compositing project with Gemini image edits. ## 2. What worked
- ffprobe + ffmpeg frame extraction at computed timestamps [L387-L399].
- Mirrored-PSNR symmetry check located the true front-facing frame in a rotating turntable [L82-L88], reused [L427-L430].
- Contact sheets (hstack/tile) for human review [L62-L70], [L579].

## 3. What broke
- curl on the signed URL returned a Cloudflare bot-challenge page; ffmpeg "EBML header parsing failed". Fixed by fetching bytes through a real browser (Chrome DevTools) [L16-L52].
- Browser-side file write hit "Access denied: path ... not within any of the configured workspace roots"; retargeted into the project dir [L46-L52].
- drawtext labeling failed twice (zsh arrays, parser); rewritten with textfile= [L89-L99].
- cropdetect returned empty bounds (skip default; dark-on-dark); replaced by a Python bright-pixel bounds finder [L460-L476].
- Source video vanished when the user moved it mid-session [L407-L430].
- Several filter_complex failures (dimension mismatches, malformed crop) [L788], [L1170-L1218], [L1379].
- Chained color-key + perspective warp silently degraded alpha (43% → ~21% opaque) [L916-L929].
- Gemini image edits failed in many distinct ways (too small, missing details, extra limbs, no-op, deleted elements, border broke chroma key) [L129-L171], [L204], [L227], [L237-L251], [L712], [L724-L758].

## 8. Durable lessons
- Support arbitrary direct/signed URLs, not just YouTube or local files; plain HTTP clients failed against Cloudflare and a browser-based fallback was needed [L16-L52].
- Validate downloaded bytes before decoding ("HTML masquerading as video") and surface a clear error [L17-L21].
- Temp/staging paths must be inside allowed workspace roots [L46-L47].
- Turnaround use case wants canonical-angle detection (symmetry), not just evenly spaced sampling [L82-L88].
- Pixel-diff "did this edit change anything" check before reporting an edit done [L238-L251].
- Deterministic image ops (crop, paste, warp, layer) are first-class; every generative placement failed, every deterministic one succeeded [L892].
